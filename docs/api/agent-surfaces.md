## What is fixture-driven until E4 lands

E4 rewrites the Rust tool catalog (`crates/shogun-mcp/src/tool_catalog.rs`: descriptions,
annotations, the core 22 freeze). Until it does:

- `apps/api/fixtures/tool-table.json` is maintained by hand to the plan's §7.1 list and marked
  `"source": "fixture"`. A test asserts its names equal §7.1 and its cost units equal
  `pricing.ts`. E4 adds the export (`shogun-mcp --export-tool-table`, name to be confirmed), CI
  regenerates the fixture from it, and the `source` field changes.
- The server card, the OpenAPI `x-mcp.tools` block and the CLI's read-only set
  (`packages/cli/src/readonly-proxy.ts`, pinned to the fixture by a test) all follow the fixture.
- The OpenAPI document covers the routes `apps/api` and `apps/router` serve today. The core's
  `/v1/state/*`, `/v1/memory/*`, `/v1/actions/*`, `/v1/export` routes are added when E4 exports
  `rest_routing.rs` the same way.

## Identity

One module, `apps/api/src/wellknown/identity.ts`, holds the name (`io.github.torutesu/shogunagent`),
display name, version (`0.1.0`, equal to `SKILL.md` and the `shogunagent` npm package), short and
long descriptions, provider and URLs. `apps/api/test/wellknown.test.ts` pins `server.json`,
`.claude-plugin/*.json`, `smithery.yaml` and `SKILL.md`'s version to it.

## Deployment settings (apps/api)

- `AGENT_CARD_SIGNING_KEY` — optional Ed25519 private key (PKCS#8 PEM, or the 32-byte seed as
  hex / base64). Unset: the card is served without a `signatures` field. A value that is not an
  Ed25519 key stops boot.
- `AGENT_MCP_URL` — the MCP endpoint the documents name when it is not `<PUBLIC_BASE_URL>/mcp`.
- `apps/api/incidents.json` — the public incident history: `[{ id: "inc_<slug>", title, severity:
  "minor" | "major", started_at, resolved_at | null, affected: [route templates], updates: [{ at,
  text }] }]`. An open `major` incident makes `/health` answer 503.
